# 2026-08-16 — Phase 5 wrap-up

## Cybersecurity
- Login is now **ID number / username + password → OTP → session** with a **10-minute lockout** after 5 failed attempts.
- Email field appears **only** in the forgot-password flow.
- Fixed the [[mysql-timezone-skew]] bug that silently disabled the lockout (wrote `locked_until` with MySQL `NOW()` in UTC).

## Student status
- `students.status` += **`enrolled`** (additive). Portal surfaces the 5 canonical labels: **Enrolled · Active · Graduated · Transferred · Dropped** via `getStudentStatusLabel()`.

## AI chat widget
- Pure-LLM floating chat on every portal page ([[includes/student-chat.php]] + [[api/student-ai-chat.php]]) — personalized with the student's context; low-confidence → the exact registrar-referral fallback.
